GAME STYLE FINAL ASSET PACK

This archive contains the approved bright premium blue-gold pirate/naval style that you liked.
All file names are intentionally explicit so Codex can understand where each image should be used.

Suggested use:
- Put this whole folder into your project under: assets/style_pack/
- Use files from 00_full_screens as global visual references.
- Use crops from folders 01-05 as direct references for specific UI blocks.
- Do not blindly stretch every crop; some files are reference components rather than production-ready sliced UI.
- Chests are in folder 05_rewards_and_chests.

FOLDERS:
00_full_screens -> complete reference screens
01_main_menu -> main menu blocks
02_battle -> battle UI blocks
03_campaign -> campaign UI blocks
04_shop -> shop UI blocks
05_rewards_and_chests -> daily/premium chests and reward chest icons
