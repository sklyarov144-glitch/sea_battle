Файлы эмоций персонажей для Codex / game assets

Рекомендуемая папка в проекте: public/assets/characters/
Формат имен: <character>_<emotion>.png

Эмоции:
- neutral: нейтрально / обычная реплика
- teach: обучение / объяснение
- hit: радость: игрок попал
- miss: промах игрока / лёгкое огорчение
- hurt: тревога: по игроку попали
- victory: победа / восторг
- defeat: поражение / грусть

Персонажи:
- admiral: Адмирал-наставник
- navigator: Штурман-наставница
- engineer: Корабельный механик
- strategist: Мудрый стратег
- corsair: Капитанша-корсар
